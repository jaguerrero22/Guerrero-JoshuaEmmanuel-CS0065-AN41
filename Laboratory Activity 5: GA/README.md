# Sentiment Analysis

Python programs for CS0065 Laboratory Activity 5: GA

- `sentiment_analysis.py` — Analyzes 10 sentences using TextBlob and summarizes the results.
- `challenge.py` — Counts happy and sad words to determine the sentence’s tone.

## Run
Install TextBlob with `python -m pip install -r requirements.txt`.

Run `python sentiment_analysis.py` or `python challenge.py`.

Keep the `positive and negative words` folder beside `challenge.py`.

Dataset: [Hu and Liu Opinion Lexicon](https://www.cs.uic.edu/~liub/FBS/sentiment-analysis.html).
