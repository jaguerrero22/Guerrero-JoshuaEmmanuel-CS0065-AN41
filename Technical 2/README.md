# Technical 2: Rule-Based Vacuum Agent

## Overview

This program simulates a simple vacuum agent that cleans two rooms, Room A and Room B. Each room can be either Dirty or Clean.

## How It Works

- The agent starts in Room A.
- If the room it's in is Dirty, the agent cleans it.
- If the room is Clean, the agent moves to the other room.
- The simulation runs for the number of steps entered by the user.
- After every step, the program displays the agent's action and the state of both rooms.

## Requirements

- Python 3
- No external libraries required
